## 维护规则

- 已完成的一次性执行计划应移入 `docs/archive/`。
- 已完成计划中仍有独立未完成项时，先迁入 `TODO.zh_CN.md`，再归档原计划。
- 未执行计划必须在文档顶部标注阶段、可用性和实施前复核入口。
- 长期路线和当前专项计划保留在本目录；稳定参考说明保留在 `docs/reference/`。
- 新计划应写清当前问题、目标、边界、验收方式和可能过期的部分。
