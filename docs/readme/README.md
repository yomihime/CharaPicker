# README 多语言补充

本目录存放根目录 `README.md` 的多语言补充版本。根目录 `README.md` 仍是默认入口和简体中文首页。

## 当前文件

- `README.zh_TW.md`：繁体中文补充版本。
- `README.en_US.md`：英语补充版本。
- `README.ja_JP.md`：日语补充版本。

## 维护规则

- 版本号、运行命令、主要文档入口变更时，应同步检查本目录所有 README。
- 根 README 的个人实验性质和 vibe coding 声明应同步到补充语言版本，避免不同语言对项目成熟度产生不同预期。
- README 语言应优先清楚、自然、克制；少写功能堆叠式总结，多写当前真实能做什么、还不稳在哪里。
- 不要在多语言 README 中加入只适用于单次开发任务的内容。
