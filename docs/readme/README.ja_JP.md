# CharaPicker (日本語)

[简体中文](../../README.md) | [繁體中文](README.zh_TW.md) | [English](README.en_US.md)

## これは何か

CharaPicker は、個人実験として作っているデスクトップツールです。アニメ、漫画、動画、画像、音声、テキスト素材からキャラクターに関係する情報を整理し、それを追跡可能なナレッジベースとキャラクタープロファイルに落とし込むことを目指しています。

成熟した商用ソフトではなく、重要なデータをそのまま預けるための本番ツールでもありません。このプロジェクトはかなり純粋な vibe coding です。試しながら書き、動かしながら作り直し、AI の助けも借りてアイデアを素早くコードにしています。ドキュメントでは、今できること、まだ不安定なこと、使う側で判断が必要なリスクをなるべく明確に書きます。

## 解決したいこと

- 素材を毎回最初から分析し直さない。一度処理した結果は、できるだけ再利用可能なナレッジベースに残す。
- キャラクターカードを一回の自由回答だけで作らない。後続の生成では、構造化された結果と証拠を優先して読む。
- 長い処理をブラックボックスにしない。抽出、スキップ、失敗、集約の流れを UI で読めるようにする。

## 現在の状態

- 1.0 は最初の安定版ベースラインです。現在のワークフロー、データ境界、アップグレード経路が継続可能なバージョンとしてまとまりました。実素材の抽出品質と一部の高度な品質判断には、引き続き人による確認が必要です。
- 公式バイナリは現在 Windows x64 のみです。ソース実行は Python `>=3.10` をサポートし、配布パッケージは固定された Windows ビルド環境で作成されます。
- 最新の配布物と各バージョンの変更点は [GitHub Releases](https://github.com/yomihime/CharaPicker/releases) と [更新ログ](../../CHANGELOG.md) を参照してください。

## 今できること

- プロジェクトを作成し、素材を取り込み、元ファイルを `raw/` に残しながら作業用の入口を `materials/` に置く。
- 動画、画像、音声、テキストの 4 種類の素材をスキャンし、プレビューまたは正式抽出の run plan を作る。
- ZIP、CBZ、EPUB、テキスト PDF、7z、RAR、CBR を制御付きで前処理し、既存のテキストまたは画像の流れに渡す。
- 共通ミドルウェア経由で OpenAI-compatible または DashScope のクラウドバックエンドを呼び出し、token usage を記録する。
- 抽出中の重要なイベントをログだけでなくインサイトストリームに表示する。
- プロジェクト内のキャラクターカードを作成、編集、カバー切り抜き、プレビュー、コンパイル、インポート、エクスポートできる。
- 正式ナレッジベースから CharaPicker JSON をコンパイルし、Markdown、HTML、Character Card V2 JSON、AstrBot 公式人格 JSON、補助コピーリストを書き出せる。

## まだ不安定なところ

- 実素材の抽出品質はまだ調整中です。特に複数話、複数メディア、長いテキスト文脈では検証が必要です。
- キャラクターカードの競合解決、品質評価、証拠の取捨選択には、まだ多くのサンプルが必要です。
- `facts.json`、`targeted_insights.json` など初期のナレッジベースファイルには、安定した自動書き込みループがありません。
- クラウドモデルの呼び出しには費用が発生し、失敗、拒否、幻覚も起こり得ます。重要なキャラクター情報は人間が確認してください。
- ローカルモデル実行はまだ接続されていません。ダウンローダー、ランタイム検出、UI のプレースホルダーがあっても、ローカル推論をサポートしていることにはなりません。

## データ、プライバシー、更新

- `projects/` はユーザーデータのルートです。重要な設定とキャラクターカードについて直近の有効なバックアップを 1 つ保持し、破損検出時には復元手段を提示しますが、完全なバックアップ機能ではありません。重要な更新前には `projects/` と `config.yaml` を自分でコピーしてください。
- アップデーターは検証済みパッケージをインストール先の `download/` に保持し、上書き対象の旧プログラムファイルを `update_backup/` にバックアップしてから、新版プログラムファイルをその場で上書きします。`projects/`、`config.yaml`、`log/`、`bin/`、`models/` は移動しません。ポータブル版の更新は自動ロールバックを保証しないため、失敗時は保持された ZIP を手動で上書きできます。
- `config.yaml` には API Key が含まれる場合があります。現在はローカルのアプリディレクトリに保存され、OS の資格情報保管庫では暗号化されません。共有したりバージョン管理へコミットしたりしないでください。
- クラウドモデルへ送信した素材は端末外へ出て、選択したプロバイダーの料金、プライバシー、コンテンツポリシーに従います。利用権限のある素材だけを処理してください。
- 公式ダウンロード先は本プロジェクトの [GitHub Releases](https://github.com/yomihime/CharaPicker/releases) のみです。現在の Windows バイナリは Authenticode 署名されていないため、不明な発行元または SmartScreen の警告が表示されることがあります。
- 同名の `.sha256` はダウンロードしたバイト列を、GitHub artifact attestation は GitHub Actions のビルド元を確認します。どちらも Windows の発行元署名ではありません。検証コマンドは[リリースパッケージ規約](../reference/release-packaging.zh_CN.md)を参照してください。

## 要件

- Python `>=3.10`
- 公式 Windows x64 パッケージでは、Python を別途インストールする必要はありません。
- 主な依存関係：
  - `PyQt6>=6.6`
  - `PyQt6-Fluent-Widgets>=1.5`
  - `pydantic>=2.6`
  - `pypdf>=6.14.2,<7`

## 対応入力

- 直接素材：一般的な動画、静止画像、音声、TXT/Markdown/JSON、SRT/ASS など。
- 制御付き前処理：`.zip`、`.cbz`、`.epub`、`.pdf`、`.7z`、`.rar`、`.cbr`。
- PDF 初版は既存テキストのみを抽出し、OCR は実行しません。暗号化 PDF、DRM EPUB、パスワード付きアーカイブは明示的に拒否されます。
- 7z/RAR/CBR にはローカルの 7-Zip が必要です。アプリはプロジェクト内 `bin/`、`PATH`、Windows 標準インストール先、`CHARAPICKER_7ZIP_PATH` を確認し、7-Zip を自動ダウンロードしません。
- 入れ子のコンテナは再帰展開しません。元コンテナは `raw/` に保持し、派生素材と出典マッピングは `materials/derived_inputs/` と前処理 manifest に保存します。
- 通常の ZIP/7z/RAR 内の動画は展開しません。動画は独立した素材として明示的にインポートしてください。CBZ/CBR は漫画画像ページのみを受け付けます。
- 直接動画の前処理には FFmpeg が必要です。利用できない場合はキャンセルする、すべての動画をスキップして他の素材を続ける、または管理対象の FFmpeg ランタイムをダウンロードして再試行できます。
- 音声と動画のセリフ情報は字幕または Whisper transcript を優先します。ネイティブ音声／動画理解は視聴覚的な手掛かりだけを補い、利用可否はプロバイダー、API schema、具体的なモデルに依存します。

## インストール

まず [uv](https://docs.astral.sh/uv/getting-started/installation/) をインストールし、ロック済み環境を同期します：

```powershell
uv sync --locked
```

## 実行

```powershell
uv run --locked python main.py
```

## ビルド

```powershell
uv sync --locked
build.bat
```

- 出力は `release/` ディレクトリに作成されます。
- よく使う例：
  - `build.bat --tag=vX.Y.Z-beta`
  - `build.bat --version=X.Y.Z --stage=beta`
  - `build.bat --local`

## 主な機能

- プロジェクト単位の素材管理（`projects/{project_id}`）
- プロジェクト内キャラクターカード管理と CharaPicker JSON 母本
- 抽出段階のインサイトイベントストリーム（Insight Stream）
- キャラクターカード Markdown、HTML、Character Card V2 JSON、AstrBot 公式人格 JSON、補助コピーリストのエクスポート（継続的に改善中）

## 開発メモ

- 本プロジェクトは `core` / `gui` / `utils` の責務分離を維持する。
- UI の表示文言は `i18n/` で管理し、長期的なハードコードを避ける。
- 実行時リソースは `res/` に統一する。
